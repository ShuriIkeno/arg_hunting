# arg_hunting

ARGをAIが画面操作だけで攻略し、その過程をデータとして残すリポジトリ。

| ディレクトリ | 内容 |
|---|---|
| `argkit/` | 共通の道具：ログ仕様（`FORMAT.md`）、操作・記録・集計ツール、ダッシュボードのテンプレート |
| `eidolie/` | 第四境界 GUEST ARG「三人組アイドルEIDOLieは■■なのか」の記録（全44ページ、エンドA〜F） |
| `.claude/skills/arg-play/` | Claude向けの攻略・記録手順 |

新しいゲームを始めるときは `argkit/README.md` を参照。
